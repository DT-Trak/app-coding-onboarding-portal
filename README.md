# DT-Trak coder training portal

Static HTML prototypes for the **DT-Trak medical coder training portal**. Pages use Bootstrap and are intended to be embedded in **Microsoft Power Pages** (see comments at the top of each HTML file for layout and Liquid placeholders).

## Pages

| File | Purpose |
|------|---------|
| `index.html` | Training dashboard (home) |
| `02-modules.html` | Modules listing |
| `03-module-player.html` | Module player |
| `04-resources.html` | Resources |
| `05-checklist.html` | Checklist |
| `project-dashboard-live.html` | Project dashboard |

## Preview locally

Open any `.html` file in your browser, or from this directory run:

```bash
python3 -m http.server 8080
```

Then visit `http://localhost:8080/`.
